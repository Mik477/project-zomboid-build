PROJECT ZOMBOID FRIENDS BUILD

Target: Project Zomboid 42.20.3, Steam build 24909800

1. Start Project Zomboid and join the host once. Accept the server Workshop list and wait until every download finishes. The first connection may fail because the custom mods are not installed yet.
2. Close Project Zomboid and its hosted server.
3. Extract the entire ZIP.
4. Double-click Install.cmd.
5. In the official ZombieBuddy installer, choose Install or update and patch Both launch modes. Close Steam if that installer asks you to.
6. Start Project Zomboid and join the host again.
7. Approve only the Java-mod fingerprints expected from this package, then restart when prompted.

The server download must provide ZombieBuddy, Better Vehicle Dynamics, SecretZ, and Trash and Corpses before Install.cmd runs. The installer exact-hash checks those Workshop copies before installing their dependent patches.

Run third-party\ZombieBuddyInstaller_v4.2.exe directly later to update or uninstall ZombieBuddy.

The package contains repo-owned mods and generated Java patches. It does not redistribute Steam Workshop mods. Existing files and the client activation list are backed up beneath Zomboid\Backups\project-zomboid-build before replacement.
