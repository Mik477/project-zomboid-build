PROJECT ZOMBOID FRIENDS BUILD

Target: Project Zomboid 42.20.3, Steam build 24775755

1. Extract the entire ZIP.
2. Close Project Zomboid and its hosted server.
3. Double-click Install.cmd.
4. If prompted, subscribe to the required Workshop prerequisites and wait for their downloads. The installer exact-hash checks ZombieBuddy, Better Vehicle Dynamics, SecretZ, and Trash and Corpses before installing their dependent patches.
5. In the official ZombieBuddy installer, choose Install or update and patch Both launch modes.
6. Start Project Zomboid and join the host. Project Zomboid/Steam will download the remaining Workshop items.
7. Approve only the Java-mod fingerprints expected from this package, then restart when prompted.

Run third-party\ZombieBuddyInstaller_v4.2.exe directly later to update or uninstall ZombieBuddy.

The package contains repo-owned mods and generated Java patches. It does not redistribute Steam Workshop mods. Existing files and the client activation list are backed up beneath Zomboid\Backups\project-zomboid-build before replacement.
